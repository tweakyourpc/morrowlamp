# Agent instructions

## The Sunken Crown, Remastered

Work on the remaster (`remastered.html`, `js/remastered/`, `tools/blender/`, `tools/voice/`,
`remastered/`) is coordinated through **`docs/remastered/HANDOFF.md`**.

- Read it before changing anything, and check it against the code and `git status`.
- Update it whenever a milestone or goal is reached, planned, changed or dropped, and before you
  stop with work unfinished: the milestone table, "In flight", "Next actions", and a dated log
  line. Record Chris's decisions there and do not re-ask them.
- GPU-capable Blender or render work must be handed to legion first through the repository's
  worker scripts. Run it locally only as a fallback after confirming legion is unreachable.
